Manual steps when requested

  1. Sign in at Xcode → Settings → Accounts and ensure the shared development team has an Apple Development certificate.
  2. Enable Settings → Privacy & Security → Developer Mode, restart, then confirm Enable with the phone passcode.
  3. If iOS blocks WDA, trust its profile under Settings → General → VPN & Device Management.
  4. Install TikTok from the App Store and sign in to every handle entered above.

Manual steps when requested

  1. Install Android platform-tools so adb is on the PATH of the process running this dashboard.
  2. On the phone: Settings → About phone → tap Build number seven times, then Developer options → USB debugging.
  3. Tap Allow on the “Allow USB debugging?” prompt and tick “Always allow from this computer”.
  4. For the accessibility bridge: install the bridge APK, enable it under Settings → Accessibility, then press Set up the driver here to read its token and forward the port.
  5. Install TikTok from Play and sign in to every handle entered above.
