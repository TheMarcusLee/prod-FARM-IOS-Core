Connect a phone

Android: turn on Developer options, then USB debugging, connect the cable and tap Allow on the phone.

iPhone: connect the cable, unlock, and accept Trust this computer. If Developer Mode has never been enabled, pairing with Xcode makes the setting appear.

Android driver
adb replays input over the cable or wireless debugging. The accessibility bridge runs an app on the phone and needs nothing attached once it is set up.

If a step asks for something

  1. Sign in at Xcode, Settings, Accounts, and make sure the development team has an Apple Development certificate.
  2. Turn on Settings, Privacy and Security, Developer Mode, restart, then confirm with the phone's passcode.
  3. If iOS blocks WebDriverAgent, trust its profile under Settings, General, VPN and Device Management.
  4. Install TikTok and sign in to every handle entered above.

If a step asks for something

  1. Install Android platform-tools so adb is on the PATH of the process running Backline.
  2. On the phone: Settings, About phone, tap Build number seven times, then Developer options, USB debugging.
  3. Tap Allow on the "Allow USB debugging?" prompt and tick "Always allow from this computer".
  4. For the accessibility bridge: install the bridge APK, turn it on under Settings, Accessibility, then press Set up the driver here.
  5. Install TikTok and sign in to every handle entered above.
